# 剧本格式 + 人物小传 + 资产编号（改编自 SBG skill，图文连载适配版）

完整原版见 `sbg-original-skill.md`（GitHub liangdabiao/Seedance2-Storyboard-Generator，2k★）。
本文件是图文连载场景的精简适配版。

## 一、人物小传模板（设定圣经的人物卡）

```
C01 [角色名]
视觉形象：[年龄] + [外貌特征：脸型/眼睛/发型发色] + [服装细节含鞋子] + [标志性道具/动作]
身份背景：[社会身份] + [与主角关系] + [过往经历]
核心标签：[标签1]、[标签2]、[标签3]
性格特点：[正常状态] → [压力下表现] → [爆发/转折时]
金句："[最能代表角色的台词]"
```

**要求**：
- 视觉形象这段是生图时的角色一致性锚点，定稿后**逐字固定**，每次生图原样拼进 prompt
- 必须含鞋子描述（防半身图）、发型发色、脸型
- 反派也不要设计太丑，保留特征但外形有辨识度
- 禁止参考真实演员长相

**示例：**
```
C01 吴邪（伪纪实版）
视觉形象：二十八岁，清瘦书卷气青年，短发微乱，戴黑框眼镜，穿灰白色旧冲锋衣，内搭褪色黑T恤，深色工装裤，磨损登山鞋，左手腕一块旧电子表。
身份背景：古董店小老板，爷爷是退休地质勘探员，父母早逝。
核心标签：好奇心重、嘴硬心软、越怕越往前凑。
性格特点：平时懒散随性 → 遇到怪事后强迫自己冷静 → 触及爷爷的秘密时变得偏执。
金句："爷爷留下的东西，我一样都不敢丢。"
```

## 二、剧本正文格式（△ 分镜体）

```
第X集
X-X [日/夜] [内/外] [场景名称]
道具：[道具列表]
出场人物：[角色列表]

△ 【空镜】[开场氛围镜头：画面、光线、氛围]
△ [镜头2：景别+构图+动作]
角色名（os）：[内心独白，字幕用]
△ [反应镜头：表情、肢体]
角色名：[对白]
△ [动作序列，用 → 连接连续动作]
【字幕：xxx】
△ 【闪回】…【闪回结束】
角色名（vo）：[画外音]
△ 【空镜】[结尾氛围镜头]
```

**规则：**
1. 每个镜头以 `△ ` 开头
2. 景别术语：远景/全景/中景/近景/特写/大特写；图文不需要运镜词，但要写清构图（俯拍/平视/过肩/对称/对角线）
3. 对白标注：`（os）`内心独白（画面可见人但嘴不动）/`（vo）`画外音（人不在画面）/`（情绪）`带情绪
4. 动作序列用 `→` 连接：`他扒开碎石 → 手电光扫过洞壁 → 手突然停住`
5. 感官细节：视觉（颜色/光影/构图）+听觉（写进描述，如"风声贴着地皮刮"）+触觉
6. 无法拍摄的词禁用："心里想、意识到、感到绝望" → 换成可拍的画面

## 三、分镜表（剧本→逐图生产指令）

```
| 图号 | 景别 | 画面内容 | 旁白/对白 | seedream prompt（本图独有部分） |
|------|------|----------|-----------|--------------------------------|
| 01 | 全景 | 黄昏的老式台球厅，主角俯身瞄准 | "我今年20岁…" | 破旧台球厅内景，黄昏暖光… |
```

**节奏分配（25图/集标准版）：**
| 段落 | 图数 | 作用 |
|------|------|------|
| 平静日常铺垫 | 8-10 | 建立人设+生活质感+埋第一个伏笔 |
| 异常事件 | 4-6 | 打破平静的那个东西出现 |
| 调查升级 | 4-6 | 主角被卷进去，线索递进 |
| 恐怖预警卡 | 1 | PIL 纯代码画，节奏闸门 |
| 悬念收尾 | 2-3 | 停在最吊胃口的画面，不解释 |

**单集结构公式**：冲突前置 + 情绪拉扯 + 阶段揭示 + 结尾留钩。第一图就是钩子（强画面/强反差/强悬念），禁止平铺直叙介绍背景。

## 四、场景/道具资产

- **场景 S01-S99**：场景中不出现人物；每个重要场景准备正打/反打/全景三种描述（连载里反复用）
- **道具 P01-P99**：纯白背景单独展示的描述（用于道具特写图）；与悬念/反转挂钩的道具要标注"线索道具"
- **色彩规划**：开场灰白压抑 → 发展暖黄/灰蓝对比 → 高潮暗红 → 结尾苍茫；每集在设定圣经里登记主色调
- **视觉母题**：选 1-3 个元素贯穿全剧（参考帖=旧地质图册；林冲=风雪/长枪/酒葫芦）

## 五、集数衔接（图文版"尾帧→首帧"）

每集最后一张图的**场景+构图+光线**登记进设定圣经；下一集第一张图承接同一场景或同一物件特写，观众一眼知道"接上了"。

## 六、质量自检

- [ ] 每图旁白≤40字，有信息增量
- [ ] 景别有变化，无连续3张同景别
- [ ] 角色出场时 prompt 拼了完整人物卡描述
- [ ] 结尾是悬念不是结论
- [ ] 伏笔台账已更新
- [ ] 免责声明+AI生成标注已写进发布文案
